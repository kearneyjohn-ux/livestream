    Getting the GoPros on screen

    Each GoPro joins the Starlink Wi-Fi and sends a live stream to the internet. Paste each camera's watch link into one half of this screen. Watch it on any phone, tablet or laptop, anywhere.

    Easiest: YouTube Live (free, about 5–10 s behind)

    1. In YouTube Studio → Create → Go live → Stream, set up two streams (one per camera), each with its own stream key. Set them to Unlisted and Ultra-low latency, and turn Auto-stop off so a Starlink dropout doesn't end the broadcast and change its link.
    2. In the GoPro Quik app, connect to the first camera, choose Live → RTMP, pick the Starlink Wi-Fi, and enter rtmp://a.rtmp.youtube.com/live2/ followed by that camera's stream key. Go live, then do the same for the second camera with the other key.
    3. Copy each stream's link (Share → Copy link) and paste one into each half here.

    Least delay: your own stream server (about 1 s behind)

    Run MediaMTX on a small cloud server with an https address. Point the cameras at rtmp://your-server/truck1 and rtmp://your-server/truck2, then paste https://your-server:8889/truck1 and …/truck2 here (WebRTC). An …/index.m3u8 link from its HLS port works too, with a few seconds more delay.

    Tips

    • Two streams share the Starlink upload. Use 720p on the cameras if either one keeps buffering.
    • A camera that drops out is reconnected automatically. The coloured dot shows each feed: green live, amber waiting, red problem.
    • Share makes a watch link to text or email. It opens straight to the cameras, locked as you set them up: viewers can only go full screen and turn sound on or off. Change something? Send a new link.
    • Sound starts off. Tap Sound on on one camera; YouTube and Twitch have their own speaker button.
    • A feed dropped out? Tap the power button on it to turn that camera off: the other fills the screen and the dropped one stops using data. Turn on at the bottom brings it back.
    • Layout → Picture in picture shows one camera full screen with the other in a small window. Swap changes which is which; the corner button on the small window moves it.
    • Cars: under Change, pick which car a camera is on. Its number, class, driver and navigator show on the feed. Add, edit or remove cars keeps the list.
    • Camera mounted upside down? Tap the rotate button on that camera, or pick Upside down under Change. Rotation, car number and crew names go into the watch link, so set them before you send it.
